# Where each layout comes from

The reader relies on the record layouts below. Code cites a row by its id (`R1` ...), and
`tests/it/provenance.rs` fails when a cited id has no row here.

Sources:

- **K**: the Kaitai Struct specification `coreldraw_cdr.ksy` (MIT, notice in `LICENSE-kaitai.txt`),
  https://github.com/kaitai-io/coreldraw_cdr.ksy/blob/9d8e2704b946961f5114115f1a488750a3c86ed0/coreldraw_cdr.ksy
- **KR**: the README and the `bin/cdr-unpk` script of the Kaitai Struct specification (MIT), at
  the same commit as K,
  https://github.com/kaitai-io/coreldraw_cdr.ksy/blob/9d8e2704b946961f5114115f1a488750a3c86ed0/README.md
  and https://github.com/kaitai-io/coreldraw_cdr.ksy/blob/9d8e2704b946961f5114115f1a488750a3c86ed0/bin/cdr-unpk
- **Z**: the PKWARE ZIP specification, APPNOTE.TXT version 6.3.10,
  https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT, and RFC 1951 (DEFLATE),
  https://www.rfc-editor.org/rfc/rfc1951
- **F**: the magic database of the `file` utility (BSD-2-Clause),
  https://github.com/file/file/blob/b778217dbd35/magic/Magdir/images and
  https://github.com/file/file/blob/b778217dbd35/magic/Magdir/riff
- **PR**: the PRONOM registry's signatures for versions 1.0, 2.0 and 4.0,
  https://pronom.nationalarchives.gov.uk/fmt/467.xml,
  https://pronom.nationalarchives.gov.uk/fmt/466.xml and
  https://pronom.nationalarchives.gov.uk/fmt/465.xml
- **S**: own inspection of the bytes of public sample files, checked against the picture each file
  carries of its drawing where it has one (versions 2 and 4 to 25; files of versions 1 and 3 carry
  none). The files come from:
  - **TP**: https://telparia.com/fileFormatSamples/image/cdr/, by file name
  - **LT**: https://git.libreoffice.org/libcdr-test at commit
    `dafe4fe53d685d89df20a5c0bb18f318ccefb4a8`, `testset/<version>/<file>`
  - **UC**: https://svn.code.sf.net/p/uniconvertor/code/formats/CDR/testing%20base/ at revision
    434, by file name
  - **TDF**: attachments to The Document Foundation's bug tracker,
    https://bugs.documentfoundation.org/attachment.cgi?id=<id>
  - **NR**: Natural Resources Canada's tactile maps,
    https://ftp.maps.canada.ca/pub/nrcan_rncan/raster/tactile/approach-approch/cdr/banff_ap_en.cdr and
    https://ftp.maps.canada.ca/pub/nrcan_rncan/raster/tactile/atlas-atlas/cdr/ab_en_br.cdr
  - **DM**: the clip art of https://discmaster.textfiles.com/browse/31541, by file name

Status: `public-spec` (K, KR, Z, F or PR), `sample` (S), `unconfirmed` (a point no source states
and no sample file shows; listed so it can be checked against a file, with what the reader does
when it is wrong).

Public specifications cover only parts of versions 1 to 4: the rows that cite K, F or PR, such as
the version 3 fill (R34) and page settings (R38). The other rows of those versions rest on the
sample files they name.
The test inputs are the synthetic files that `src/synth.rs` builds from the rows below; no sample
file is committed.
