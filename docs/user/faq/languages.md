---
title: Which languages does VectorCraft speak?
description: The interface languages VectorCraft ships with.
order: 30
verified: 0.10.0
---

The interface speaks English, Czech, German, Hungarian, Japanese, Korean, Traditional Chinese, Simplified Chinese, Spanish, French, Italian, Russian and Ukrainian. Brazilian Portuguese can be chosen too: its menus and panels are translated, but some status and error messages stay in English. To switch, choose **Edit** › **Preferences…** › **User Interface** and set **Language** (on macOS, **VectorCraft** › **Language**).
