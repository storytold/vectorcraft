Install VectorCraft, then start a document or open an existing file.

## First steps

1. [Install VectorCraft](install.md).
2. Start VectorCraft. If no window appears, see [VectorCraft does not start](../troubleshooting/app-does-not-start.md).
3. Choose **File** › **New…** to start a document, or **File** › **Open…** to open a file. See [Open a file](../guides/open-a-file.md).
4. Draw with the [Pen Tool](../guides/draw-with-the-pen-tool.md) and save with **File** › **Save**.

## Where VectorCraft keeps your settings

VectorCraft keeps its settings in the file `ui.json` in `%APPDATA%\VectorCraft`. Its log files are in the `logs` folder next to it.
