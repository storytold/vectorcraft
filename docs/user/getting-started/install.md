Download the Windows installer (`.msi`) for your PC from the [latest release](https://github.com/storytold/vectorcraft/releases/latest), run it, then start VectorCraft. The easiest way to find the download is the [VectorCraft page on getartcraft.com](https://getartcraft.com/apps/vectorcraft).

## Windows 11

1. Open the [latest release](https://github.com/storytold/vectorcraft/releases/latest).
2. Download `vectorcraft-<version>-windows-x64.msi`. It fits most PCs (64-bit Intel and AMD). In the file names, `<version>` is the version number, for example `0.10.0`.
3. Run the file and follow the installer. On the **Shortcuts** page, **Create a desktop shortcut** is ticked. Untick it if you do not want one. VectorCraft is always added to the Start menu.
4. Start VectorCraft.

Other Windows files in the release:

| Your PC                      | Installer                                 | No install (unzip and run)                         |
|------------------------------|-------------------------------------------|----------------------------------------------------|
| 64-bit Intel or AMD          | `vectorcraft-<version>-windows-x64.msi`   | `vectorcraft-<version>-windows-x64-portable.zip`   |
| Snapdragon and other ARM PCs | `vectorcraft-<version>-windows-arm64.msi` | `vectorcraft-<version>-windows-arm64-portable.zip` |
| 32-bit Windows               | `vectorcraft-<version>-windows-x86.msi`   | `vectorcraft-<version>-windows-x86-portable.zip`   |

Windows 11 is always 64-bit, so on Windows 11 pick an x64 or arm64 file.

The installers and executables are code-signed. The release also has a `SHA256SUMS.txt` file with a checksum for every download.

## Install with ArtCraft Launcher

ArtCraft Launcher lists VectorCraft and installs the build that fits your system. See [ArtCraft Launcher](https://getartcraft.com/docs/craft-launcher) for how to install the launcher and use it to install and update apps.

## Other systems

The release also has builds for macOS, Linux, FreeBSD and the web. These pages cover Windows 11 only.

## Update

Download the newer files from the [releases page](https://github.com/storytold/vectorcraft/releases). Each release lists what changed.
