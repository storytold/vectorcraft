Use **File** › **Save** to keep your work in VectorCraft's own format, and **File** › **Export** to make SVG, PNG and other files for use elsewhere.

## Save your work

- **File** › **Save** saves the document. VectorCraft's own format is `.vectorcraft`.
- **File** › **Save As…** saves under a new name or in another format. **File** › **Save a Copy…** saves a copy and keeps working on the original.
- Saving as **PDF-compatible .ai** writes a file that Illustrator opens as plain artwork. It does not contain Illustrator's editing data.

## Export one file

1. Choose **File** › **Export**, then **Export As SVG…**, **Export As PNG…** or **Export As…** for other formats.
2. Pick a file name and folder.
3. In the options dialog, set the options and confirm. The PNG options include **Resolution:**, **Background Color:**, **Anti-aliasing:** and **Interlaced**.

A path that ends in `.svgz` writes a compressed SVG.

## Export artboards in several sizes and formats

1. Choose **File** › **Export** › **Export for Screens…**.
2. On the **Artboards** tab, choose **All**, a range, or **Full Document**, and tick the artboards you want. **Include Bleed** adds the bleed.
3. Under **Export to:**, choose a folder. **Create Sub-folders** and **Open Location after Export** are optional.
4. In the **Formats:** rows, set the **Scale**, a **Suffix** and the **Format**. Use **+ Add Scale** for more sizes. The formats include PNG, JPG, WebP, GIF, SVG and PDF.
5. Click **Export Artboard**.

To export collected assets instead, use the **Assets** tab. The button then reads **Export Asset**.

## Other export commands

- **File** › **Export** › **Save for Web (Legacy)…**
- **File** › **Export Selection…**
- **File** › **Package…**
