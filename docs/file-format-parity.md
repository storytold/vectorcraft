Every format Illustrator opens, places, saves or exports, against VectorCraft's format table (`FORMATS`,
`OPEN_EXTS`, `PLACE_EXTS` in `crates/engine/src/cmd/fileio/formats.rs`). Illustrator's list comes from its public
documentation (helpx "file formats" and Save/Export pages), not from its installed bundle: the clean-room rule
forbids reading the install. Part of [target-app-parity.md](target-app-parity.md).

**Fidelity** is estimated unless a test is named. Test sources: unit and property tests per crate
(`crates/svg/tests`, `crates/pdf/tests`, `crates/format/tests/prop_format.rs`), import fuzzing
(`crates/engine/tests/import_fuzz.rs`), the Affinity corpus (`cargo xtask corpus --affinity`, 51 pinned public
files, CI job `affinity-corpus.yml`). There is **no real-world Illustrator corpus**: test inputs are written
from the public specifications, and users' own `.ai` files are used locally only.

## Summary

Ordinary File > Save offers Save As when its own location refuses writes with a terminal permission/read-only error (#6146). The picker suggests the original filename and format, keeps the original options when the format is unchanged, and opens the chosen format’s Save options when it changes. It starts in Documents (home or host default if unavailable). Cancel leaves the document modified at its original path. Explicit Save As/Copy/export, recovery failures and Close/Quit keep their existing error dialog. Non-UI saves return `READ_ONLY_LOCATION: <reason>` without opening a panel. Focused UI regressions passed; engine regression execution and native panel acceptance pending; format scores unchanged.

EPS editing-data follow-up (2026-10-16): both mesh-corner layouts (with and without opacity)
read in RGB, CMYK and gray. Vector opacity-mask art and its Clip, Invert, Disabled and Linked
flags are retained. Winding-declared legacy compound member groups keep their shared paint even
when followed by `9 () XW`. Fully rasterized print pages are compared using the same filtered

## The main format: `.ai`

The format that decides beta. Illustrator's `.ai` is a PDF (or, for old files, PostScript) plus Illustrator's
private editing data. VectorCraft:

- **Reads** the PDF page (vectors, text, images, colour, transparency, layers via optional content) and the
  *structure* of the editing data (below). Opens Illustrator EPS the same way through its own PostScript
  Level 3 interpreter. A `.ai` in PostScript form (versions 3 to 8, and what Rhino and other CAD apps
  write) is its own editing data: it opens through the layers its program has, compared with its page
  when the program runs, from the layers alone when it names its prolog without including it (#1027), and with its art on one
  layer when it has no layers (Illustrator 3, and image editors' exported paths: storytold/photocraft#6036).
  A file without layers whose program runs opens through that layer too, compared with its page, so its
  objects keep what only the format records (locks, for example); it opens as its page when the layer can't be used.
  A multi-layer mask (`Mb` … `Md` … `MB`) comes in as a clipping group in each layer it covers, each
  clipped by a copy of the mask's path.
  An opacity mask's art of one shown object, other than a guide or a clipping path, opens as that object in the
  editing data of a `.ai`, EPS or PDF; other art opens in a group. Art in the mask that sets no paint of its
  own paints with the paint before the mask's dictionary, as the writer leaves out paint that doesn't change.
  Type from the text document keeps auto leading as auto, each line taking the paragraph's share
  (Auto Leading) of the largest type on it ([Line and character spacing](https://helpx.adobe.com/illustrator/using/line-character-spacing.html)),
  and the paragraph's hyphenation options and tab stops. Stroked type keeps its stroke's cap, join and miter limit. Type filled or
  stroked with a pattern keeps its pattern, placed in the document as a path's pattern fill would be: a character's paint names
  an art style of one paint, and the pattern is in that style (its colour in the text document is black). A pattern the file
  doesn't define, or a style that isn't a pattern, keeps the colour as before. Type keeps its manual kerning (key 8 of a story's text, thousandths of an em after a character). Its font is an installed face of the PostScript name its font record gives: one of exactly that name, case and punctuation included (`SampleSans` isn't the face named `SAMPLESANS`, nor `SampleSerif-Bold` the one named `SampleSerifBold`), when one is installed, else one whose name differs only in them. The type takes that face's own family and style, not another family spelled alike (`SAMPLE INK` beside `Sample/Ink`, whose PostScript name is `SampleInk`). Among those faces the record's version (key 5, name ID 5) picks the one in that version when it is installed; a version that isn't installed gives the first, without a note. The type names the face's version when its family and style alone resolve to another installed copy. Copies that share their family, style and version (an OpenType and a TrueType build of one release) can't be told apart: only the first of them loads. Type that a PostScript program sets, and legacy `.ai` type, take the face of their font's name the same way, with no version to read. Area type of one
  frame whose last lines the file sets but which don't fit here (the fallback font, or a descent
  past the frame's bottom) may get a frame taller from its bottom, by its lines' deepest descent plus 0.05 pt and only when that shows more of those lines, with a warning when it does.
  RGB in the PDF page's `ICCBased` spaces keeps the file's numbers in a `.ai` (the `uncalibrated_rgb`
  import option, on for editor documents, off for PDFs), so `.ai` files tagged with a non-sRGB RGB profile
  open with different, unconverted RGB colours than before.
  A PDF-compatible `.ai` opens on its PDF part's trim boxes (its artboards), the bleed boxes round them
  becoming the document's bleed, so art in the bleed shows outside the artboard, within the bleed guide (#1266).
  With editing data explicitly requested, a single artboard larger than its 14,400 pt capped PDF page opens at its full size, with a warning (#6865).
  A PDF saved with its editing data (`AIPDFPrivateData`) opens the same way.
  The swatches of a version 7 `.ai` palette, which carry no names, come in named by their spot color, gradient or
  values.
  When the PDF part of either can't be read (a stream the import refuses), the file opens from its editing
  data alone, with the PDF part's error as its first warning, and without the bleed and File Info the PDF
  part would give (part of #4366).
- **Writes** a PDF-compatible `.ai` (Save As › `ai`). With the option `editingData` (on by default, Include
  Editing Data for Other Apps) every page's `PieceInfo` also carries an editing copy of the art in
  `AIPrivateData` streams, in the form VectorCraft's `.ai` reader reads: layers and sublayers, groups, paths with
  their fills and strokes (a compound path as one path of all its subpaths), process, spot and global colors, swatches and color groups, guides,
  hidden and locked objects, object names, every artboard with its name, the active artboard (`CropAreaActive`: the
  view's active artboard when the app saves or exports the file, else the one the document opened on, else the first;
  the reader opens the file on it, and so does the restore of the native document a file VectorCraft saved carries),
  the transparency of objects and layers
  (opacity, blending mode, isolation, knockout and knockout shape), objects' opacity masks, and clipping groups and
  clipping layers clipped by a path or compound path, linear and radial gradients on fills and strokes (with their
  stops' opacity, midpoints and spot colors, elliptical radials and focal points) and gradient swatches, and
  patterns whose tiles make a grid and hold their art within the tile, with no pattern fill in that art, as
  pattern definitions with their fills, strokes and swatches. Embedded images are written with their pixels (gray,
  RGB or CMYK ink amounts, and their alpha channel) and linked images as placed files with their path, their folder
  relative to the document's and a preview; images that can't be decoded or have more than 33,554,432 pixels are
  written as their outlines filled mid gray, images of 16 bits a channel at 8 bits, and linked images in opacity
  masks, pattern tiles and symbols as embedded images, each with a warning. Every symbol is written as a symbol
  definition (its art, its registration point and its place in the Symbols panel's order, nested symbols included)
  and its instances as symbol instances with their matrix, name, hide, lock, opacity, blending mode and opacity
  mask; instances with a fill, appearance changes, isolation, knockout or knockout shape of their own, instances of
  symbols with 9-slice guides or pattern paint, instances in pattern tiles or in art cut to a clipping object,
  instances scaled almost flat, instances that turn, mirror or scale symbols holding type, live objects,
  instances written as their art, shapes with rounded live corners or strokes written as outlines or brush art,
  instances that scale their symbol more than 100 times and instances on the layers of a large canvas are written as their art, pattern fills in a
  symbol's art are written as their tiles cut to the shape, symbols past 4,096 are written only as their
  instances' art, and symbols' 9-slice guides, export types and dynamic type are left out, each with a
  warning. Paths, compound paths and groups with live effects keep them as art styles: the drawn look, the object
  itself and the style it names, for a fill and a stroke at most in solid colors or the object's gradient (a stroke
  with its variable-width profile), filled by the non-zero rule, with Drop Shadow, Inner Glow, Outer Glow, Feather,
  Round Corners, Scribble, Convert to Shape, Offset Path, Outline Object or Outline Stroke, and groups with Pathfinder ›
  Add. Groups keep them when their members are paths, compound paths or such groups, without effects of their own; when the
  group's effects change its members' outlines, a member's strokes are plain lines, and its fills are not pattern
  fills written as tiles or gradients that fit their object. The look holds the object's vector art, without the shadow, glow or feather. Other objects with
  live effects are written as their vector art with their geometry effects applied, and their other effects, such as
  Drop Shadow, the glows and Feather, are left out with a warning. A path, compound path or group linked to a graphic style names it when it has the style's
  appearance and the style is written; other links to graphic styles, those on a styled group's members included, are
  left out with a warning. The Graphic Styles panel's styles are written in its order, with their fills, strokes, transparency and effects (Warp,
  Transform, Free Distort, Pucker & Bloat, Twist, Zig Zag and Gaussian Blur too). Styles with gradient or pattern fills,
  with fills, strokes or effects the reader doesn't read back, with a name another style has, with names over 1,024
  bytes and past 4,096 styles are left out with a warning. A panel with no style written opens with a new document's
  styles, with a warning. No art style is written on a large canvas. The Brushes panel's Calligraphic brushes, and its
  Scatter and Art brushes with their art, are written in its order: Scatter and Art brushes in Tints or keeping their
  art's colors, Art brushes that stretch their art along the path from left to right at 100% unflipped without
  overlap, and art of paths and compound paths with points and groups with members, with one solid fill and one
  plain stroke each. Other brushes,
  Pattern and Bristle brushes among them, and brushes past the number or the art VectorCraft's reader reads are left
  out with a warning; no brush is written on a large canvas. A path or compound path with a Calligraphic brush, or
  with an Art brush in Tints whose art bends along the path, keeps the brush on its stroke; other brushed strokes are
  written as their brush's art. A document that uses a new document's brushes writes none until a path keeps one on
  its stroke; then the brushes are written, and the file opens without the new document's Pattern and Bristle brushes
  and its Art brush with other options.
  Point type, area type (with its rows, columns,
  gutters and first baseline, threaded frames included) and type on a path are written as text: a text object for
  each, naming its story in the text document, with the characters, fonts, sizes, leading, tracking, baseline shift,
  scales, solid fills and strokes, capitals and paragraph alignment, indents, spacing and direction; other character
  and paragraph attributes are left out with a warning. A font of the text document's font set that is a variable font
  also names where in its design space the type is set (each `fvar` axis in the font's order, as 16.16 fixed: the named
  instance's setting, or the run's own Variable Font setting) and its version string, so the type doesn't open at the
  font's default instance (#6388); two settings of one font are two fonts of the set. A static font names no design space, and names its version when its PostScript name alone would give the reader another installed copy (another version, or a copy of that name in another family), so the type opens in its own copy again; two such copies are two fonts of the set. A version longer than the reader takes (256 bytes) can't pick a copy: type in a copy its name alone doesn't give back is then reported as losing attributes. Each run's baseline direction is written in the form the reader
  below reads it: 1 when Standard Vertical Roman Alignment is on, 2 when it is off and 3 for Tate-chu-yoko; the
  document's defaults and the normal character style carry 1. A run with both Tate-chu-yoko and Standard Vertical Roman
  Alignment is written as Tate-chu-yoko, with the type attributes warning. Type in opacity masks, pattern tiles, symbols and art cut to a
  clipping object, mirrored type, turned or unevenly scaled area type and type on a path, area type in an open frame,
  type on an open path whose ends meet, area type that flows around a text wrap, type of only white space, threads of
  type on a path, threads whose frames differ in orientation, type and stories past the sizes VectorCraft's reader reads, and
  type with inline graphics, ruby, gradient or pattern paint or an appearance or opacity mask of its own, other patterns, other clipping objects and live
  objects (placed documents included) are written as plain filled and stroked paths, and freeform gradients, gradients along
  or across a stroke and gradients without stops, with more than 256 stops or without extent as their average
  color, each with a warning. Gradients that dither or mix their colors perceptually are written as classic
  gradients, and gradient stops linked to global process colors as their colors, each with a warning. The opacity
  and blending mode of single fills and strokes, opacity masks on layers, the placement of pattern swatches that
  move, turn or scale their pattern, and the effects of objects written without an art style, other than geometry
  effects, are left out.
  The editing copy also holds the document's variables, data sets, the data set shown and the variables' lock as
  the variable library the reader reads, with the objects bound to visibility variables, the type bound to text
  variables and the linked images bound to image variables. Bindings to layers, to type written as outlines and to
  graphs, graph values, values that don't fit their variable, linked files that aren't absolute paths, the path `/`
  alone and paths from the root whose first part starts like a drive (`/C:`), drive and network paths with white
  space at either end, values of variables whose names have a colon, and a data set shown that isn't one of the data
  sets written are left out, with a
  warning, as are variables and data sets whose names are empty, repeated, longer than 255 characters or start or
  end with white space, variables past 256, data sets past 1,000, bindings past 100,000 or to objects whose XML ids are
  longer than 255 characters, values past 200,000 text lines and values in all, and names and values past
  8,388,608 bytes in all ([variables](https://helpx.adobe.com/illustrator/desktop/automate-visualize-data/automate-actions/work-with-variables.html)).
- **Writes** a legacy `.ai` of version 7 (Save As › `ai` › Version: Legacy (version 7), `aiVersion: "7"`): the
  PostScript form, from the published *Adobe Illustrator File Format Specification* version 7.0
  ([PRONOM fmt/423](https://www.nationalarchives.gov.uk/PRONOM/fmt/423)), which apps reading `.ai` open with its
  structure (#868). It keeps layers (names, order, visibility, lock), groups, compound paths, clipping groups,
  solid colours, linear and radial gradients and RGB images. A colorized image whose pixels are all black or white
  is written as a 1-bit image mask (ImageMask 1) in its color, with its white pixels clear, and opens colorized
  again; other colorized images are flattened or omitted as the Transparent Images setting below says. The format has one artboard: each artboard chosen in
  the options dialog's artboard picker (thumbnails to check, default all) is a file of its own,
  `{name}-{artboard}.ai` when there are several. It has no transparency: objects are written opaque, and images
  with see-through pixels, opacity or a blending mode are flattened (an opaque image of themselves and the art
  under them, clipped to where they show, along a smooth outline traced at the image's own resolution; that art stays) or omitted (Transparent Images,
  `transparentImages: "flatten"|"omit"`). Type is written as editable text objects (point type, area type and type
  on a path, with their fonts' PostScript names, sizes, colours, alignment, indents, leading, tracking and
  scaling, and the Standard Vertical Roman Alignment and Tate-chu-yoko marks as `Tv` and `TY`), which the reading
  app sets in those fonts; characters outside Windows-1252, vertical type, ruby, inline
  graphics and gradient or pattern fills make that type outlines, and so do rotated characters (Character Rotation,
  which a version 7 text object can't hold: the outlines keep the rotation, and the type is no longer editable text
  in the file), and Text: Outlines (`outlineText: true`) writes
  all type as outlines. The format can hide only layers: hidden objects go to a hidden layer of their own above
  their layer, are omitted, or are made visible (Hidden Objects, `hiddenObjects: "layer"|"omit"|"visible"`).
  Sublayers become groups; appearances, effects and brushes are expanded; object names are left out; layer
  names, spot color and gradient names and the title are written in Windows-1252, with `?` for characters outside
  it (two spot colors or two gradients whose names become the same are numbered).
  The file is also a PostScript program that runs: its prolog, a procedure set of VectorCraft's own written from
  the PostScript Language Reference, gives the format's operators their meaning, so it prints and previews
  (gradients filled with their first stop's colour, type left to the apps that read the format). VectorCraft
  opens a file with that prolog from its program, as the format.
- **Known failures in users' files:** layer structure flattened or multiplied (#951: 109 layers instead of
  14; #868: round trip with Illustrator 2018 loses layers and groups), some files 4× slower to open since the
  editing data is read whole (#758), live effects that are not read or have settings that are not read, and
  brushes come in as their drawn look (#637; pattern fills are read since #1025, and symbols and their instances
  open live, as do the symbols of a symbol library without layers); legacy `.ai` without the prolog opens since #1027, its legacy type (`To` … `TO`) since #868; guides
  open as ruler guides and guide paths since #5057 (#779).
  Type under a Warp effect is compared with the art saved with it: type that draws as that art stays editable with
  the effect live, and type that draws differently, or that the file's limit of checks has no check left for, opens
  as that art, with one note that counts them. Type stays live without a comparison when the saved art paints
  nothing or draws type of its own, in frames of threaded type, when a text variable binds it, and when its text
  object doesn't come in as one text object.
  Legacy `.ai` type keeps its manual kerning pairs (`Tk`, `TK`: the kerning after the character before the
  pair, or at a line's start the space before its first character), its discretionary hyphens (`T+`, `T-`) as
  soft hyphens and its hyphenation language (`XL`); a line breaking value (`TG`) and Japanese layout rules
  (`Xu`, `Tu`) are not kept, with a warning. Legacy `.ai` saves write manual kerning as `Tk` and soft hyphens
  as `T+`.
  Legacy `.ai` type keeps its paragraphs' letter and word spacing (`TC`, `TW`), hanging punctuation (`Tq`) and
  hyphenation (`Th`); its tab definitions (`Xb` … `XB`) set its paragraphs' tab stops. Paragraphs in a row with
  the same attributes share one copy of them while the text object is read, and those copies hold at most
  1,048,576 stops. The paragraphs and linked frames of one text object then get at most 1,048,576 more copied
  stops. Paragraphs and frames past either limit take the default stops, with a warning. Its special characters
  (`TS`) join the story, and end render (`Te`) and pop text matrix (`TM`) are read and ignored. Its type in a
  font re-encoded with encoding pairs of its own (`TZ`) is decoded with those pairs, and with the file's encoding
  (`TE`) for the codes they leave out unless the `TZ` sets `useDefault` to 0. Its type in a CJK composite font,
  whose name ends in a predefined CMap (`HeiseiMin-W3-83pv-RKSJ-H`) and which no `TZ` gives encoding pairs, opens
  with the font named without the CMap. Its codes are read by the CMap's code space, mapped to CIDs and then to
  Unicode by the character collection's CID-to-Unicode CMap, and codes the CMap does not map are dropped. A `-V`
  CMap is read with its `-H` form's codes, and a 0x0D byte ends a paragraph. The Unicode CMaps `Uni*-UCS2`, `-UTF8`,
  `-UTF16` and `-UTF32` are read as Unicode. VectorCraft reads the predefined CMaps that craft-pdf does not carry
  (`RKSJ`, `78-RKSJ`, `78ms-RKSJ`, `78-EUC`, `78`, `Add`, `Ext`, `NWP`, `GB`, `CNS1`, `KSC`, `B5` and the Hong Kong
  `-B5` sets other than `HKscs-B5`) with its own choice of the nearest carried CMap, which can give a different
  character for some codes, and decodes `GBT`, `GBT-EUC`, `GBTpc-EUC`, `CNS2` and `KSC-Johab` type byte by byte with
  the CMap removed from the font name. A font whose name ends in `-H` or `-V` without a `TZ` that gives encoding pairs
  is read with the `H` or `V` CMap.
  Its area type with several linked areas opens as threaded frames, one for each area with its own matrix,
  and the story flows through them.
  Its writing direction (`TV`) opens as vertical type. VectorCraft keeps one direction for each text object, the
  one in force at its first character, with a warning when a later character has another. Vertical point type
  starts at the origin of `Tp`'s matrix on the column's center line, which is VectorCraft's own placement. Its Kumi
  blocks (`Ty`, and `TY` in horizontal type) open as Tate-chu-yoko runs, which is VectorCraft's own mapping. A `TY`
  block in vertical type opens unmarked, and two blocks with nothing between them open as one block. Its upright
  Roman characters (`Tv`) open with Standard Vertical Roman Alignment. VectorCraft's own layout rule also sets a
  run of two or three half-width digits across the column in vertical type, inside or outside a block and with
  either `Tv` value. Its binding punctuation (`Tg`) opens as Burasagari's Force setting when on and as no
  Burasagari when off, which is VectorCraft's own mapping; the repeat character, line breaking (`TG`) and
  Japanese layout rules (`Xu`, `Tu`) are not read.
  Legacy `.ai` type set in rendering modes 4 to 7 (`Tr`, text used as a mask) is a clipping path of its
  clipping group, as a `W` path is, and the mode lasts into later text objects. Type in linked areas, in
  wraparound text or in a compound path doesn't clip, with a warning. A `Tr` operand that is not a whole number
  from 0 to 9 leaves the mode as it was.
  Legacy `.ai` placed EPS files in the version 7 form (`` ` `` … `~` with no `%AI5_BeginPlace`) are read like
  other placed files without a preview: as the page's art in their box. Graphs (`%_Gs` … `%_GS`) come in as their
  drawn art. A grouped column, stacked column, line or area graph also keeps its table, type, axes and settings
  when every record has the shape and values the version 7 specification's appendix A gives
  ([the specification](https://13thmonkey.org/documentation/fonts/AI7FileFormat.pdf), printed pp. 109–112
  and 146–158), its table holds at least one number, its art draws the plot's left and bottom edges, and each series'
  group is tagged once and paints its marks with one fill and one stroke, which the graph keeps as that series'
  paint; Graph Data then edits it. Other graphs (pie and scatter graphs, graphs with designs or
  customizations, records of later versions) come in as plain groups, paths and type, with a note. Saving a graph to
  `.ai`, in either form, writes its art without its data or settings, with a warning.
  Legacy `.ai` patterns in the version 7 form (a list of `@` and `&` layers, `_ &` for the tile's background)
  open as pattern swatches, with a fill's offset, scale, rotation, reflection and shear applied before its
  matrix. Legacy `.ai` linked images in
  the version 7 form (`(path) modified XG`, then `XF` with no samples) come in as linked images of their files,
  showing a placeholder where the image goes until the file is relinked in the Links panel. A path stored in
  the classic Mac OS form (`Disk:Folder:file.tif`, with a colon and no `/` or `\`) is named by its last part, and
  relinking looks for that name.
  A 1-bit gray image whose `XI` or `XF` has ImageMask 1 comes in colorized by the fill color set before it,
  or by black when that fill is not a solid color. VectorCraft's own rule is that the pixels that open black
  with ImageMask 0 take the color and the others are transparent.
  An image whose color space `XC` sets to one ink (`n [… (name) /Separation] XC`) comes in as a grayscale image of
  its tints (black at 100 %) colorized by the ink (its spot swatch, or a process plate's CMYK color), its alpha channel
  as its opacity mask (#6350).

### Illustrator's private editing data

The app's own editing copy of a file (an EPS after its `%%EOF`, a `.ai`'s `AIPrivateData` streams, a PDF's `AIPDFPrivateData` streams when it was saved with the editing data (#868), Zstandard or zlib, the EPS's in ASCII85) is not documented as a whole. VectorCraft reads its structure: layers and sublayers (names, order, visibility, lock, printing, preview, dimming, colour), groups as they were nested, compound paths (painted by their last path, or the last painted one, with the paths of groups inside them kept as their paths: #1410), clipping groups and layer clipping (several clipping paths in a clipping group, a layer or an opacity mask's art clip to their intersection, and a compound path of clipping paths stays one clip; a filled clipping path keeps its fill, which paints under the art it clips, except the path of a mask that covers several layers, whose fill is read as a path of its own in the layer that holds the mask's path, and a compound clipping path whose subpaths paint differently, whose filled subpaths are read as a compound path of their own under the art it clips; clipping paths that would nest the art past the document's 32 levels stop the editing data from being read: #5789), object names, hidden and locked objects, fills and strokes (grey, CMYK, RGB, named and spot colours, spot colours defined in Lab with their Lab values (#1032), global process colours as global swatches at their tint; a stroke of width 0, `0 w`, on a path, a gradient-filled path, legacy type or in an art style comes in as a 0.25 pt hairline, as from PDF: #1671), linear and radial gradients, pattern fills with their patterns as pattern swatches (#1025), gradient and pattern names in the file up to their first newline (a name that another swatch, or a gradient or pattern defined earlier, already has is numbered "Sky 2"; a name without a newline is kept, and when another swatch has it, the pattern's swatch, or a named color sharing a gradient or pattern swatch's name, is numbered the same way), opacity, blend modes, isolation and knockout, embedded images where their matrix puts them, rotated ones too (#2269), with their alpha channel (CMYK images keep their ink amounts, as they do when a `.ai` opens from its PDF part, and an alpha channel that hides part of a CMYK image becomes a grayscale opacity mask), placed (linked) files as linked images in their place, each showing the low-resolution preview the file keeps of it until its file is found or relinked in the Links panel (#1264), with the folder the file keeps relative to the document's, where the link is looked for when its path is gone, placed PDF and `.ai` pages as placed documents of the [page and Crop to box](https://helpx.adobe.com/illustrator/desktop/add-and-import-files/import-other-file-types/adobe-pdf-placement-options.html) their dictionary names (`AI11 PlacedPDFPageIndex`, `AI11 PlacedPDFCropTo`; a value VectorCraft doesn't read, or a binding to an image variable, leaves a linked image), guides, and every artboard where it is, with its center mark, cross hairs, video safe areas and video ruler pixel aspect ratio. VectorCraft reads `CropAreaActive`, an `/Int` in the dictionary that holds the artboard array, as the index of the active artboard in that array, and the file opens with that artboard active; without it, or when it names no artboard that opens, the first artboard is active. It also reads the Document Raster Effects Settings (resolution, color model, background, anti-alias, clipping mask, Add Around Object and Preserve Spot Colors), the author from the header's `%%For` (an EPS's own header when the editing data's has none), swatches for the header's `%%CMYKCustomColor` and `%%RGBCustomColor` colors that the document has none of, and `%%TemplateBox` in older files; a setting with a value of another type or out of range keeps its default. Objects on Path groups open live, with their path, their objects in order along it, Pivot and Rotate; one with a dragged spacing or other options opens as a plain group. A gradient with stops in the middle runs its whole ramp across its shape, and a gradient object does not pass its fill to the next path (#1390). An object whose art style is one fill and one stroke at most (solid colours, its own gradient, a variable-width profile on a Stroke Offset stroke or written as each side's widths) with Drop Shadow, Inner Glow, Outer Glow, Feather, Round Corners, Scribble, Offset Path, Outline Object, Outline Stroke, Convert to Shape, Tweak (only when it moves nothing), Pucker & Bloat at 0 or Bas Relief (read from its settings block: [raster effects reference](https://helpx.adobe.com/illustrator/desktop/special-effects-styles/apply-filter-effects/raster-effects-reference.html), [Photoshop File Formats Specification](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/), [scripting the filter gallery](https://community.adobe.com/questions-712/scripting-support-for-the-filter-gallery-1064646)) comes in as itself with them and their saved settings. A path, compound path or group (not a clipping group) whose only effect is Transform (not with copies or Random) or a Free Distort whose corners make a parallelogram comes in as itself with it too, when neither it nor anything in it paints with a gradient or pattern and everything in it is a path, compound path or group with no opacity mask and no effects of its own; Transform that scales, rotates or reflects needs nothing in it to be stroked. Twist as the only effect is read the same way when nothing in the object is stroked: up to 180° either way (a limit VectorCraft sets) on a path or compound path whose segments are all straight, except a compound path with a guide member that reaches past its other members at an angle other than 0°, and up to 90° either way (a limit VectorCraft sets) on another path, compound path or group with no guide in it. One with more, other effects (Zig Zag, a Pucker & Bloat of another amount, a Free Distort with other corners), an effect setting that is not read (an unknown key, a missing or out-of-range value, a Scribble with a color of its own), a variable-width stroke with one centered width array, dashes aligned to corners, a brush other than a Calligraphic or Art one, a Calligraphic brush with settings of its own or an angle that follows the path, or an Art brush other than the ones described next comes in as its drawn look (a group named after it). Objects in a symbol defined before the file's art styles section, as newer files write it, take the same styles as the layers' objects. A path with a Calligraphic brush otherwise comes in as the path, the brush on its stroke at the stroke's weight, which scales the brush (#372), and so does a path with an Art brush, whose weight scales the art across the path, when all of these hold: the brush stretches its art along the path, unflipped, at 100% in Tints; the path's settings are the brush's own, with no entry that isn't read, no variable width and no effects; its stroke isn't a swatch; and the art is paths, compound paths and groups in solid fills, with no strokes, masks or effects, and has some length along the path. A stroke takes the brush the Brushes panel keeps under its name, and one whose name the panel doesn't keep comes in as its drawn look. Type with an Art brush keeps its drawn look under the type. A Calligraphic brush's Pressure, Tilt, Bearing and Rotation come in as those channels (a 6D Art Pen's brushes vary with the pressure, the bearing and the barrel's rotation); its Stylus Wheel varies at random. The file's Calligraphic, Scatter, Art and Bristle brushes replace the default ones in the Brushes panel, in the file's order, also when the file comes in as its PDF part (a brush library has no layers); pattern brushes and brushes it can't read are left out with a note. When the file opens from its layers, the spot colors in the art of each brush that comes in become swatches, and that art's colors count toward the document's color mode, as a pattern's do. The swatches take at most 20,000 color names in all across the brush art, and each brush-art section keeps at most 20,000 names. Each name keeps its first definition, with the color operators' names before the gradient stops' names. A spot color past those limits makes no swatch, and its color still counts toward the color mode. A spot color that the page's art, a pattern or a symbol also defines keeps the value defined there. Type keeps its art style as a live appearance whatever its stack (an Art brush aside), so it can be retyped: each fill and stroke of the style's stack (solid colours, gradients and pattern fills, placed as the drawn look places them) with its own opacity, blend mode and effects, the effects on the whole object, and where the characters paint among them; the effects read are Warp, Offset Path, Outline Object, Outline Stroke, Transform (with copies, Transform Objects, Transform Patterns and Scale Strokes & Effects; not with Random), Free Distort, Pucker & Bloat, Twist, Zig Zag, Tweak (only when it moves nothing, the file holding none of its random outline), Drop Shadow, Inner Glow, Outer Glow, Feather, Round Corners, Scribble, Gaussian Blur, Bas Relief (its detail, smoothness and light direction from its settings block, or the effect's defaults when the style holds no settings block; a settings block that isn't read keeps the drawn look) and Convert to Shape, and a style with others, or with an effect setting that isn't read, keeps the type's drawn look. Convert to Shape keeps its Rectangle, Rounded Rectangle or Ellipse, its Absolute or Relative size (a relative size in the file is added to each side) and its corner radius; a relative Ellipse, or a setting that isn't read, keeps the drawn look. The page's drawing of such a style isn't held to look like VectorCraft's where its drawn look lay. Gradients take their matrix (`Xm`, radials and skewed ones too), focal point and the order of stops sharing a ramp point; gradient meshes, a clipping path's own fill and its stroke, and the artboards' names are read too. `editingData: "always"` (`convert --editing-data`) opens a `.ai` or an Illustrator EPS from its editing data even where it draws differently from its page, which can be older, with a note. Type is made from the file's text document, whole and editable, shown or not: point type (its frame's matrix, which newer files leave out when it is neither turned nor scaled, read as none), area type (a story in several frames as threaded type) and type on a path, with its characters, fonts, size, leading, tracking, scaling, baseline shift, fill and stroke (grey, RGB or CMYK), alignment, indents and paragraph spacing (a character attribute a run doesn't set comes from its character style, then the style that one is based on, then the document's defaults); area type keeps its frame's Area Type Options rows and columns, the gutter between rows and the gutter between columns, and its first baseline (Fixed, Cap Height, Leading or x Height) with its minimum; type on a path keeps its frame's Type on a Path effect, Align to Path and Flip (a frame whose options set key 6 to true keeps their defaults), and the first frame's Spacing is fitted from the file's layout, not read from the dialog's value; the distance from the path under Align to Path is measured for each character at its size and vertical scale (in vertical type, its horizontal scale), from the top of its font's em box (Ascender), half the height of the top of its font's H (Center) or the bottom of its font's bounding box (Descender); the fit under Gravity does not reproduce the file's layout, and its glyphs can lie up to 7.4 pt from the positions the file keeps; the page's drawing of it (often in pieces) is left out. Vertical type keeps its orientation, its columns from right to left, and a run set to Tate-chu-yoko keeps that setting. When it makes the type of every text object that shows, the page's type is only compared with it, each text object keeps its own group, frame and layer, and a line break inside a paragraph stays one. Where it can't make a text object's type (a frame of another kind), that text object takes the page's type where the text document puts its lines, or else what is left of the page's type in painting order (no group around it); the page's type where made type draws stays that type's, and hidden type is left out with a note. Text wrap is read too: an object whose dictionary has the wrap options (offset and Invert Wrap), or any graphic of a legacy wraparound group (`*w` … `*W`, before or after its type, with no offset), is a wrap object, and area type below it in its layer flows around it when the file opens, threaded type included (#2763). Kerning, underline and the other character and paragraph options aren't read yet. A `.ai` saved without PDF compatibility (a placeholder page) opens from its editing data alone, its point type, area type and type on a path made from the text document. A `.ai` whose PDF part shows only text isn't taken for that placeholder when its page states an art, trim or bleed box: it opens from its editing data alone where that reads, else from its PDF part (#1387). A `.ai` whose PDF part draws nothing at all (an empty page, with or without those boxes) opens from its editing data alone where that reads too: there is no page art to check its layers against, and the empty page would lose all of it. Text objects with an appearance keep their own text and frame, type of hidden layers stays hidden, and type on later artboards lands on its text objects (#1391); area type whose frame is too short for a line of the fallback font shows its first line (the frame is made taller, with a warning in the open result) (#1392). In a PDF saved with some of its artboards, the type on each page after the first goes to an artboard of that page's size after the previous page's artboard, and only to one that leaves an artboard for each later page; the first page's artboard also leaves one for each later page. When several artboards fit a later page, VectorCraft takes the one whose art draws most like the page, and compares at most 16 artboards for all the later pages together. Symbols are read into the Symbols panel, in the file's symbol list order, with their art, their registration point and the instances in their art, and their instances come in live with their matrix, name, hide, lock, opacity, blending mode, isolation, knockout and opacity mask; a symbol whose art isn't read whole (type, placed files, an image it leaves out or anything else it doesn't read) isn't kept. A file that comes in as its page or PDF part because its editing data has no layers (a symbol library), or because its layers can't be read or used (any of the cases below), gets the symbols its editing data defines before its first layer, in the symbol list's order, while its page art stays as the page draws it. Instances of symbols it can't read, instances with appearance changes of their own (a dynamic symbol's), pattern fills whose pattern it can't read, placed files the data keeps no preview of and anything else it doesn't read make the file come in as its page (on a layer that doesn't show, they are left out of that layer), with a warning saying what. An unread object on a shown layer whose box can be found instead comes in as a group of the page's objects inside that box, named after it, with the rest of the layers and groups kept and a warning listing what came in as the page's art; the file still comes in as its page when live art or another unread object shares that page art, when the object spans two artboards or lies on an artboard that has no page, when no page art lies inside its box, when that page art is inside a page group with a clip, mask, transparency or appearance, when the object holds a frame of threaded type, when the page art uses a pattern, image or swatch that the page lacks or that differs from the editing data's, or when the page art doesn't carry its transparency (#4806). The layers' art is also compared with the page (by lightness, so colours written as their CMYK equivalents compare alike, and by whether a pixel is inked at all); the page is used when they differ by more than 5% (away from type, when all the type is made from the text document), where one draws an object the other doesn't (away from type, whose lines may be laid out afresh), and when an EPS whose page is its art's box has art printed outside it (#735). A `.ai` is not compared with its page, and its PDF part is not imported, when its text document makes the type of every text object (at least one shows, and none is drawn by the appearance of the layer or group it is in), no object is unread, no placed file has a second placement, no live envelope keeps its drawn art, it declares no large canvas, and its artboards are its pages' trim boxes one for one, in points or in the first page's `UserUnit`: it opens from its layers, with the bleed of its pages' bleed boxes. When they differ because some objects draw differently (an object in another color, or one that only one of them draws), each top-level object of the layers that holds such a difference comes in as a group of the page's objects inside its box and the layers stay, with a warning that names the layer or sublayer of each such object as the Layers panel shows it (`<Layer>` for one without a name) and how many came in from it; an export or Save As to the file's own path then needs `acknowledgeLoss: true`, and a wrap object replaced this way keeps its wrap options. The file still comes in as its page when only edges or type differ, when a difference lies outside every top-level object, when more than half of the top-level objects or more than 64 hold one, when such an object is or holds type or holds a wrap object inside a group, when the page's type of a text object that stays lies inside such an object's box, when the page's art can't replace such an object for one of the reasons above for an unread object, when matching the differences to the objects would take too much work, or when the result still differs from the page. `editingData: "always"` keeps the objects as read, and placed files at the other point their data gives are tried as well. An EPS whose page is its art's box keeps that page when it comes in through its layers, not the editing data's artboard, and a text object counts as drawn by the page by its colours, not only its lightness, so a red stroke stacked over a dark red one stays (#1102). `textAs: "outlines"` opens a `.ai` whose type shows from its PDF part, which has the outlines; `editingData: false` opens any of them as its page or PDF part only, for print pipelines (#735). A file whose import left something out (hidden text, art or layers) is never written over by an export or Save As to its own path unless `acknowledgeLoss: true` (`convert --replace-lossy`), so the original keeps what the document lacks. Where a `.ai` can't be read that way (or its layers are turned off in the import options), we read its PDF-compatible part, so Illustrator-only live objects arrive as appearance, and plain groups arrive ungrouped: that part draws each object on its own and marks only layers, clipping groups and groups with opacity, blending or a mask (those come back). Art outside the artboards isn't in that part at all (Illustrator's PDF part leaves it out), so it doesn't open; the import says so in a note (#472). Its pages still go where the editing data puts the artboards (a grid stays a grid), with the art on each, when it has as many artboards as pages, of the same sizes (#1068); the page of the artboard `CropAreaActive` names is then the active artboard. A `.ai` whose editing data has artboards but no layers also opens on that page under the same check, and its pages stay where they are. A `.ai` whose PDF part's pages are cropped to its art (each page the box of all the art, which is the editing data's bounding box) instead of its artboards opens from its layers, with its own artboards, where they draw as that page does. Its pages are laid out so that art one of them draws past its artboard (notes beside a design, which the part doesn't clip) doesn't lie over the page before it in the row, where it was taken for that page's art: the check against the editing data then found art its layers don't have there and opened the file as its PDF part, without the art outside the artboards. That part also has no paragraphs: area type is written line by line, and comes back as area type only where its font is installed and lays the lines out with the same breaks, else as a point type object per line (#508). Art off the page that a PDF does draw opens on the pasteboard.

A run of type in the editing data whose baseline direction is 1 opens with Standard Vertical Roman Alignment (https://helpx.adobe.com/illustrator/using/formatting-asian-characters.html) on, which is VectorCraft's own mapping: its half-width characters stand upright in vertical type, and horizontal type keeps the mark with no change to its layout. A run whose baseline direction is 2 or 3 (Tate-chu-yoko), or that names none in the run, its character style or the document's defaults, opens with it off. The scripting reference lists 1, 2 and 3 as the Standard, vertical rotated and Tate-chu-yoko baseline directions (https://web.archive.org/web/20170621180804/https://wwwimages.adobe.com/content/dam/Adobe/en/devnet/illustrator/sdk/CC2015_3/Illustrator%20VBScript%20Reference.pdf, page 256).
A Scatter brush in the editing data whose last 15 numbers start with 1 comes into the Brushes panel in Tints. Each brush art section is read without its frame: an unnamed, unpainted rectangle with no settings of its own at the art's bounds (within 1/1000 pt), closed, or open with its first corner again at the end. A wider frame stays in the art, and an art group with a state or look of its own (hidden, locked, isolated, knockout, an opacity, a blend mode, a name, a mask, a note or an appearance) stays a group.

An object in a pattern's art or in a brush's art takes the file's art styles in the same way as an object on a layer: with a style VectorCraft reads, it comes in as itself with its effects live, not as the look it draws. An object in a pattern's art with a style in the file's style list keeps that graphic style's id. An art styles section inside a symbol's, a pattern's or a brush's art is skipped.

Names in the editing data that aren't UTF-8 (layers, objects, artboards, colors, gradients, patterns, graphic styles, swatches, brushes, symbols, variables and data sets) are read as Windows-1252 unless `legacyNameEncoding` (`convert --legacy-name-encoding`) picks `macintosh`, `windows-949`, `shift_jis`, `gbk` or `big5`; the open result's warnings list the first three such names as read and count the rest. The text values of data sets are read in the same encoding.

## EPS Save and source protection

Feature evidence updated 2026-10-26; scores and estimates unchanged.

EPS is offered by Save As, and an opened EPS keeps its own path for ordinary Save. The EPS
Options of Save As show Use Artboards with All or Range under it, for a separate file per artboard
([saving in EPS](https://helpx.adobe.com/illustrator/desktop/save-and-export/export-files-to-different-formats/save-artwork-in-eps-format.html)),
unchecked by default (the scripting reference's EPS save options list `saveMultipleArtboards` with
a default of false,
[scripting reference](https://web.archive.org/web/20160803105056/https://wwwimages.adobe.com/content/dam/Adobe/en/devnet/illustrator/sdk/CC2015_3/Illustrator%20JavaScript%20Scripting%20Reference.pdf)).
Unchecked, Save writes one file whose bounding box fits all the visible art, as Export does,
without the artboards' background colors; an opened EPS saved back this way loses the margins its
page had. With no visible art the page is the first artboard, in its color. Naming artboards with
`artboard`, `artboards` or `range` turns Use Artboards on. Checked with two or more chosen, the
file at the path is the central file of the visible art and each artboard is also written to
`<name>_<artboard>.eps` beside it, holding that artboard. Checked with one chosen, VectorCraft
writes that artboard as the page of the file at the path alone, retaining its bounds and
transparent margins. The file the document becomes carries the whole editable VectorCraft document
in EPS comments, including other artboards. Save bounds the optional TIFF preview to
1024 pixels on its longest side (about 4 MiB of RGBA pixels), avoiding the roughly 16 MiB preview a
large artboard otherwise produces. Export keeps its existing 2048-pixel preview cap. Preview
format choices are unchanged; no public preview-resolution option exists. The EPS PostScript appearance still flattens
transparency; its existing warnings remain. This does not promise native Illustrator editing-data fidelity.

Selected-only EPS output remains available through Export. Save refuses `selectedOnly`.
An EPS opened from a preview, a partially interpreted program or damaged native editing data keeps
its source-loss warning: writing over that original requires explicit confirmation. File › Save uses
the same engine path and write-failure handling as other document formats.
