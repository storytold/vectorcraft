Vector W3K2 app icon (vectorcraft.svg, vectorcraft-small.svg and every file derived from them in this
directory: vectorcraft-1024.png, vectorcraft-macos-512.png, vectorcraft.icns, vectorcraft.ico, hicolor/).

Original artwork made for Vector W3K2 by Print That 204 ("PT": a bold black P and a Print That cyan T
on a white rounded tile, the letters outlined from the bundled open-source UI font; no third-party artwork). The file names keep their original names so the
build and packaging scripts find them. Licensed like the rest of the project, under either of

at your option.

The PNG, ICO and ICNS files are rendered from vectorcraft.svg with `vectorcraft-cli convert`.
