VectorCraft portable mode

While this file sits next to vectorcraft.exe, VectorCraft keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the VectorCraftData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move VectorCraft with its
settings. The first time VectorCraftData is created, any settings already in
%APPDATA%\VectorCraft are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders VectorCraft loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\VectorCraft) instead.
If VectorCraftData can't be written (for example on a read-only drive), VectorCraft logs a
warning and uses %APPDATA%\VectorCraft instead.
