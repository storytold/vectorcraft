# Image Trace showcase: source records

Verified 2026-11-01. These are the **exact scan files**, not just the underlying artworks.
The locally retained source bytes were compared with the direct URLs below; all five matched
byte for byte. Source scans are not added to this repository. SHA-256 identifies the full,
unmodified downloaded file before cropping, resampling or JPEG preparation.

Rights statements below are those recorded by the linked source pages. Public Domain Mark is
a status marker, not a licence granted by VectorCraft. For the PD-Art files, Commons distinguishes
the expired artwork copyright from its treatment of faithful two-dimensional reproductions;
see its [reproduction guidance](https://commons.wikimedia.org/wiki/Commons:Reuse_of_PD-Art_photographs).
This record supports review of the specific scans rather than inferring rights from an artist's age.
